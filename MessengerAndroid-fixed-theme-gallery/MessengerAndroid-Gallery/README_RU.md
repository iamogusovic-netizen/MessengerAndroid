# Messenger Android — APK с собственной галереей

Приложение открывает мессенджер по адресу `http://89.125.121.18` в Android WebView. При каждом новом запуске приложение загружает страницу с сервера заново, поэтому обновления веб-интерфейса, опубликованные на сервере, становятся доступны без пересборки APK. WebView использует стандартную HTTP-кеш-политику сервера.

Собственная галерея Android показывает фото и видео из MediaStore в нижнем окне приложения.

## Сборка APK
1. Загрузи содержимое папки в корень GitHub-репозитория, включая `.github`.
2. Открой Actions и дождись успешного workflow `Build Android APK`.
3. В завершённом запуске скачай artifact `Messenger-APK`, распакуй его и установи `app-debug.apk`.

## Обновления
- Изменения HTML/CSS/JavaScript на сервере не требуют новой сборки APK. Они загрузятся при следующем запуске приложения.
- Изменения нативного Android-кода (галерея, разрешения, уведомления и т. п.) требуют новой сборки и установки APK.

Пока используется HTTP. Перед использованием для реальных переписок настрой HTTPS и замени адрес в `MainActivity.java` на домен с HTTPS.


### Название и иконка
На телефоне приложение отображается как «Мессенджер». Иконка использует фирменную строчную букву m и фиолетовый градиент сайта.


## Тема, загрузки и разрешения

- WebView не включает принудительную тёмную перекраску сайта Android: оформление страницы остаётся таким, каким его отдаёт сам сайт.
- Файлы, которые сайт передаёт на скачивание, сохраняются системным DownloadManager в папку «Загрузки». Android показывает системное уведомление о ходе загрузки.
- Доступ к фото и видео запрашивается при первом открытии галереи, а не при старте приложения. На Android 14+ пользователь может предоставить доступ ко всем фото/видео или только к выбранным.
- Приложение не запрашивает «все разрешения» без разбора: Android не предоставляет универсального разрешения на всё, а лишние разрешения небезопасны и могут привести к отклонению приложения. Запрашиваются только необходимые для конкретной функции.
