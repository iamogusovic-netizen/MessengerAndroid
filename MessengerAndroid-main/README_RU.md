# Android-оболочка мессенджера

Актуальный Android-проект находится в `MessengerAndroid-Gallery/`. Именно эту папку собирает GitHub Actions.

## Сборка

В GitHub Actions запускается workflow `.github/workflows/build-apk.yml` при push в `main` или вручную через `workflow_dispatch`. APK публикуется как артефакт `Messenger-APK`.

## Что изменено в этой редакции

- Удалены вложенные архивные копии старых Android-проектов, чтобы не путать их с актуальной сборкой.
- Тёмные системные панели Android-приложения; приложение не вызывает API для изменения системного режима телефона.
- Встроенная в Android-оболочку панель выбора медиа получила фильтры «Все / Фото / Видео» и множественный выбор, если веб-страница запрашивает `multiple`.
- Обработка отмены выбора и результата `Uri[]`.

## Ограничения

WebView загружает сайт с `http://89.125.121.18`. Исходников сайта и backend в переданном архиве нет, поэтому их код и серверная обработка вложений здесь не изменялись. Для отправки нескольких файлов веб-страница должна использовать `<input type="file" multiple>` и сервер должен принимать несколько файлов. Если сайт запрашивает только один файл, Android корректно вернёт один.

Сборка в текущем окружении не запускалась: здесь не установлен Gradle и Android SDK. Успешность APK должна быть подтверждена запуском GitHub Actions.
