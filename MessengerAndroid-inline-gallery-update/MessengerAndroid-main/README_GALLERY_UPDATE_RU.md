# Обновление встроенной галереи

В этой версии Android кнопка скрепки в WebView перехватывается: вместо промежуточного меню сайта сразу открывается встроенное окно «Фото и видео» с миниатюрами из MediaStore. Окно оформлено в светлом стиле приложения, содержит вкладки «Все / Фото / Видео», отметки выбора и кнопку «Отправить».

## Сборка

GitHub Actions собирает проект из `MessengerAndroid-Gallery` и загружает APK как `Messenger-APK`.

## Важно про множественную отправку

Нативная галерея возвращает выбранные URI списком. Для отправки нескольких файлов сайт также должен обрабатывать все элементы `input.files`, а не только `input.files[0]`. Если серверный frontend пока отправляет только первый файл, обновите обработчик загрузки на VPS отдельно; иначе используйте выбор одного файла за раз.

Для отображения медиатеки Android запрашивает разрешение на фото и видео. При частичном доступе Android 14+ в галерее будут показаны только разрешённые пользователем элементы.
