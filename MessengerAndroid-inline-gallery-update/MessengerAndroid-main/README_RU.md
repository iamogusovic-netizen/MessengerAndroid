# Messenger Android — APK с собственной галереей

Приложение открывает текущий сайт `http://89.125.121.18` в WebView. Когда сайт вызывает стандартный выбор фото/видео, приложение показывает собственное окно-галерею на 62% высоты экрана с миниатюрами из MediaStore.

## Сборка APK без Android Studio
1. Создай репозиторий на GitHub.
2. Загрузи всё содержимое этой папки в корень репозитория, включая скрытую `.github`.
3. Открой Actions и дождись успешного workflow `Build Android APK`.
4. В завершённом запуске скачай artifact `Messenger-APK`, распакуй ZIP и установи `app-debug.apk` на Android.

Пока используется HTTP. Не вводи реальные пароли и конфиденциальные сообщения до настройки HTTPS на домене.
